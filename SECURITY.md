# Security Policy

## Supported versions

Security fixes are released for the latest minor version of the current major version only.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately via
[GitHub's private vulnerability reporting](https://github.com/pringuin/opendxp-health-bundle/security/advisories/new)
or by email to kontakt@pringuin.de.

Please include the affected version, a description of the issue and, if possible, steps to
reproduce it. We will acknowledge your report as soon as possible and keep you informed about
the fix and its release.
